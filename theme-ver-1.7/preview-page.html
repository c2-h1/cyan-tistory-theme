    Getting Started with SF Symbols

    SF Symbols is Apple's comprehensive icon library, tightly integrated with the San Francisco typeface. When you use SF Symbols in a web context, you get icons that feel native to macOS and iOS without any additional font loading — just a thoughtful CSS mask approach.

    Setting up the icon pipeline

    First, export the symbols you need as SVG from the SF Symbols app. Each symbol comes as a layered SVG with variable weights matching San Francisco's six weight variants.

    .icon {
  display: inline-block;
  width: 1em;
  height: 1em;
  mask-image: url('symbols/folder.svg');
  mask-repeat: no-repeat;
  mask-size: contain;
  background-color: currentColor;
}

    This technique lets the icon inherit color from its parent, so active states and hover effects work without any extra CSS.

    SF Symbols are Apple intellectual property. Use them only in contexts that match Apple's guidelines — typically software that runs on Apple platforms.

    Checklist before shipping

    • Export every symbol at the regular and semibold weights — mixing weights inside one toolbar reads as a rendering bug, especially on non-Retina displays where the stems land on different subpixels.
    • Check the mask fallback in Safari 15 and older, since mask-image without the -webkit- prefix silently fails there and the icon collapses to a solid square.
    • Nested rules to watch:
      • Inline icons inherit line-height, so a 1.8 body leading pushes them off the baseline.
      • Buttons need an explicit vertical-align: -0.125em.
    • 한글 본문에서도 줄바꿈이 마커 기준으로 들여쓰기 되는지 확인한다. 두 번째 줄이 마커 아래로 내려가면 안 되고, 첫 줄 텍스트 시작점에 맞춰 정렬되어야 한다.

    Ordered build steps

    1. Install the SF Symbols app and pick the symbol set you need.
    2. Run the export script:
      1. Normalize the viewBox to 24×24.
      2. Strip the layer metadata Apple ships in each file.
    3. Drop the SVGs into images/symbols/ and reference them from the mask rule above.

    Weight reference

    WeightCSS valueUse
    Regular400Body icons
    Semibold600Toolbar icons
    Bold700Empty states

    Variable weight in CSS

    Because each weight is a separate SVG, you can swap the mask source in response to font-weight — though this requires a small JavaScript shim to bridge CSS custom properties and the mask attribute.

    In practice, using the regular weight (400) for body icons and the semibold weight (600) for toolbar icons gives the right visual rhythm on Retina displays.
